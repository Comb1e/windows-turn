End the sessions you want to train on. Train a new model from all ended, labeled groups for this laptop and camera setup. Training compares models across complete sessions and keeps the original method when there is too little evidence to choose another. Each run keeps its own model and report.

Command-line training and loading a model

To train from the command line, use a new output folder. Load your downloaded model by passing its path to npm start:

.\.venv\Scripts\python.exe research/train_annotations.py data/annotations --output artifacts/photos-v1
node research/check-parity.mjs artifacts/photos-v1/model.json artifacts/photos-v1/parity.json
npm start -- --model artifacts/photos-v1/model.json

The live measurement page uses the selected annotation model. Whole-group diagnostics report how the model transfers between sessions. Repeated lighting is allowed; a separate session alone does not establish performance under unseen lighting. Screenshots do not measure motion accuracy or response delay.
